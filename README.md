# ESL Bomb Squad — DEMO

Standalone demo build (one 5-module bomb). Static files only, in `web/`.
Published to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.

Run locally: `./run_demo.sh` (tailnet-only) or `python3 -m http.server -d web`.

This is separate from the main ESL Bomb Squad project and can be deleted when no longer needed.
